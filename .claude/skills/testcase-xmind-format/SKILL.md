# XMind Test Case Output Format (Do Not Optimize)

**CRITICAL WARNING: This skill file defines the STRICT output format for test cases. DO NOT optimize, modify, or rewrite this skill unless the user EXPLICITLY specifies "modify the testcase-xmind-format skill".**

## 输出格式（XMind 可导入的 Markdown）

输出为 `.md` 文件，通过 XMind「文件 → 导入 → Markdown」直接导入为思维导图。

### 层级结构规范

```markdown
# 功能名称（XMind 中心主题）

## 模块名（一级分支）

### 子分类名（二级分支）

- TC-XXX 测试点名称（三级节点）

    - 【步骤1】场景条件 + 操作1
        - 【预期】对应步骤1的结果
            - 【优先级】P0
    - 【步骤2】场景条件 + 操作2
        - 【预期】对应步骤2的结果
            - 【优先级】P0
```

### 导入后在 XMind 中的呈现

```text
TC-001 首页头像区元素完整展示 
├── 【步骤1】玩家已登录并进入游戏主界面；观察左上角头像区
 ├── 【预期】头像区固定显示在左上角，且包含头像、等级、昵称元素
  └── 【优先级】P0
├── 【步骤2】切换账号重新进入游戏主界面；再次观察左上角头像区
 ├── 【预期】头像区展示规则保持一致，无缺失、无错位
  └── 【优先级】P0
```

### 格式要点

1. `#` 一级标题 → 中心主题
2. `##` 二级标题 → 功能模块（一级分支）
3. `###` 三级标题 → 逻辑子分类（二级分支）
4. `-` 一级列表项 → 测试点（TC编号+名称）
5. `    -` 二级列表项 → 【步骤N】节点，每个步骤都要写“场景条件 + 操作”
6. 不单独输出【前置】节点，前置条件需并入每个步骤中
7. `        -` 三级列表项 → 【预期】节点，挂在对应步骤下，只描述该步骤的结果
8. `            -` 四级列表项 → 【优先级】节点，挂在对应预期下
9. 如果多个步骤属于同一个测试主题，可以保留在同一条用例中
10. 如果某一步对应的是另一页面、另一阶段、另一链路或另一验证目标，必须拆成新用例
11. 【优先级】默认取该测试点最高优先级；如导图结构要求，也可在每个预期下重复挂同一优先级

### 多步骤/多预期的写法

```markdown
- TC-005 商品购买状态校验
    - 【步骤1】玩家背包金币=200，商店已解锁；打开商店界面并购买商品A
        - 【预期】商店界面正常打开，商品A购买成功，扣除金币100，背包新增商品A×1
            - 【优先级】P0
    - 【步骤2】玩家背包金币=99，商店已解锁；打开商店界面并购买商品A
        - 【预期】商品A不可购买，弹出金币不足提示，且不扣除金币、不发放商品A
            - 【优先级】P0
```
> 上面两步验证的仍然是同一个测试主题“商品购买状态”，所以应聚合到同一条用例中；只有当页面、链路、验证目标发生变化时，才拆成新的测试点。

### 完整用例示例

```markdown
# XXX功能测试用例

## 一、功能模块A

### 1.1 入口与展示

- TC-001 功能入口正常展示
    - 【步骤1】玩家等级>=10级，已完成前置任务；进入主界面查看功能入口按钮  
        - 【预期】主界面展示功能入口按钮
            - 【优先级】P0
    - 【步骤2】玩家等级>=10级，已完成前置任务；点击功能入口按钮
        - 【预期】正常打开功能界面，并展示所有核心元素完整
            - 【优先级】P0

- TC-002 功能入口-等级不足
    - 【步骤1】玩家等级<10级；点击功能入口按钮
        - 【预期】弹出提示"等级不足，需要10级"，且不进入功能界面
            - 【优先级】P0

### 1.2 异常与边界

- TC-003 网络异常时的处理
    - 【步骤1】已打开功能界面并断开网络；观察当前界面数据
        - 【预期】界面继续展示当前缓存数据
            - 【优先级】P1
    - 【步骤2】已打开功能界面并断开网络；点击当前功能内的关键操作按钮
        - 【预期】提示"当前网络不可用"
            - 【优先级】P1

## 十、连点防抖（通用无需每关回归）

### 10.1 关键操作防重复

- TC-100 连点-确认按钮
    - 【步骤1】确认弹窗已打开；快速连续点击"确认"按钮3次
        - 【预期】仅触发1次操作，不重复扣除资源，不重复发放奖励
            - 【优先级】P0
```

## 层级对比

| 层级 | 内容 |
|-----|------|
| 三级节点 | TC-XXX 测试点名称 |
| 四级节点 | 【步骤N】场景条件 + 操作 |
| 五级节点 | 【预期】（挂在对应步骤下） |
| 六级节点 | 【优先级】P0（挂在对应预期下） |
