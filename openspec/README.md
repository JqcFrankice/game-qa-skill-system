# OpenSpec workspace

This directory is managed by OpenSpec CLI 1.3 or later.

- `changes/<change-name>/`: active changes with proposal, design, delta specs, and tasks.
- `changes/archive/`: completed changes archived by the CLI.
- `specs/`: current capability specifications after changes are archived.
- `config.yaml`: project-wide OpenSpec schema and authoring rules.

Use `openspec` on macOS/Linux. Use `openspec.cmd` in Windows PowerShell.

Game design documents that are only testcase inputs belong under `examples/requirements/`, not at the OpenSpec root.
