# 本地标准与示例说明

本目录同时包含仓库运行规范和本地测试夹具，两者采用不同的版本管理策略。

## 仓库依赖

- `测试用例标准.md`：`generate-testcase` 强制读取的等级与书写规范，必须纳入版本管理。

## 本地夹具

其余 Excel、XMind、MindManager、DOCX 和历史 Markdown 仅用于人工对照、格式回归或真实需求演练，默认由 `.gitignore` 排除，不属于 Skill 运行时依赖。

需要把某个夹具升级为公共示例时，应先：

1. 去除项目敏感信息和大体积冗余资源。
2. 移入 `examples/` 下的明确分类目录。
3. 在对应 README 中登记来源、用途、格式和维护状态。
4. 增加可重复的验证方式后再纳入版本管理。
