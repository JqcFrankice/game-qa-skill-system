# 阵营竞技系统策划文档

> 来源：Z_阵营竞技.xlsx（功能逻辑、活动流程、交互、UI逻辑、配置内容、参考、美术需求）

---

## 一、设计目的

1. 为头部玩家提供固定周期的 PVP 竞技玩法。
2. 提供竞猜功能，增强围观、讨论与参与感。
3. 形成“报名 → 预赛 → 淘汰赛 → 竞猜 → 结算奖励 → 冠军展示/拍卖”的完整活动链路。

---

## 二、活动概述

1. 活动按周固定时间开启，满足解锁条件的玩家需主动报名参赛。
2. 玩家会根据自身历史最高战力阵容，被分配到四个阵营之一，在阵营内完成预赛与淘汰赛。
3. 预赛结束后，各阵营前 8 名进入淘汰赛。
4. 淘汰赛期间，所有解锁该活动的玩家均可参与竞猜。
5. 当日活动结束后，会展示四位阵营冠军，并发放对应奖励；活动结束后开启全服拍卖。

---

## 三、活动开启与入口规则

### 1. 开启条件

1. 活动解锁条件配置在 `function_level`。
2. 活动开启日期配置在 `activity_time`。
3. `activity_time` 中配置项：
   - `function_id=CAMP_ARENA`
   - `open=1`
   - `entrance=1`
   - `order=5`
   - `name=阵营竞技`
   - `week=1|2|3|4|5|6|7`
   - `begin_time=04:00`

### 2. 活动阶段时间

1. 报名开始时间：比赛日当天 `08:00`。
2. 活动正式开始时间：`20:30`，同时停止报名并进入预赛阶段。
3. 活动入口阶段展示规则：`20:30` 视为“进行中”。
4. 当日比赛结束至次日 `04:00`，活动界面展示四位阵营冠军与本轮排行榜信息。
5. 次日 `04:00` 后清理本轮展示数据。

---

## 四、报名与阵营分配

### 1. 报名规则

1. 只有在报名阶段主动报名的玩家才能参与本届阵营竞技。
2. 未报名玩家不能进入后续预赛与淘汰赛。

### 2. 阵营分配规则

1. 报名开始时，系统提前为玩家分配阵营。
2. 分配依据：根据玩家**历史最高战力阵容**中，各阵营神将战力占比最高的阵营作为参赛阵营。
3. 若出现相同战力占比，依次按以下优先级判定：
   1. 阵营人数较多的阵营
   2. 主角所属阵营
   3. 默认阵营顺序
4. 若玩家穿戴了变身卡，则主角阵营按变身卡阵营计算。
5. 报名后所属阵营固定，本次活动内不再修改。

---

## 五、预赛规则

### 1. 基础规则

1. `20:30` 正式开始预赛，同时停止报名。
2. 预赛各阵营同时进行。
3. 玩家初始积分为 `100`。
4. 同积分情况下，按玩家战力从高到低排序。

### 2. 比赛节奏

1. 预赛总轮次：`20` 轮（`camp_arena_pre_round=20`）。
2. 每轮单位时间：`10` 秒（`camp_arena_pre_time=10`）。
3. 玩家可实时调整自身阵容，也可实时看到对手阵容变化。
4. 默认服务器战斗，玩家是否播放战报不影响活动主流程，战报可跳过。

### 3. 积分规则

1. 初始积分：`100`（`camp_arena_pre_initial=100`）。
2. 胜利加分：`+10`。
3. 失败减分：`-10`。
4. 轮空视为胜利。
5. 积分下限不能小于 `0`。

### 4. 匹配规则

1. 第一轮：按当前排序两两匹配（1 打 2、3 打 4，以此类推）。
2. 第一轮后：从第一名开始，向下寻找第一个**未对战过**的玩家作为对手。
3. 被挑选玩家不再重复寻找对手。
4. 若不存在未对战过的可匹配玩家，则该玩家轮空。

### 5. 出线规则

1. 20 轮结束后，各阵营前 `8` 名晋级淘汰赛。
2. 未出线玩家在预赛结束后发放参与奖。

---

## 六、淘汰赛规则

### 1. 基础规则

1. 淘汰赛仍然只在**同阵营内**进行。
2. 赛制为：八进四 → 四进二 → 二进一。
3. 每场采用**三局两胜制**。
4. 各阵营同一轮次同时进行。
5. 每场比赛时长 `90` 秒（`camp_arena_final_time=90`）。
6. 玩家可在准备期间调整阵容，并可实时查看对手阵容变化。
7. 默认服务器战斗，战报可跳过。

### 2. 匹配规则

1. 八进四：1 打 8、2 打 7、3 打 6、4 打 5。
2. 四进二：
   - 1/8 胜者 vs 4/5 胜者
   - 3/6 胜者 vs 2/7 胜者
3. 二进一：半决赛胜者进入决赛。

### 3. 奖励发放

1. 每轮淘汰赛结束后，给被淘汰玩家发放对应名次奖励。
2. 决赛结束后发放冠军/亚军奖励。

---

## 七、竞猜规则

1. 淘汰赛过程中，所有已解锁该活动的玩家均可参与竞猜，不要求必须参赛。
2. 每轮淘汰赛开始后的 `90` 秒准备阶段内可下注。
3. 玩家可以在任意一场比赛中任选一边参赛者下注。
4. 每轮淘汰轮次**只能选择一个玩家**下注。
5. 下注**不消耗元宝**。
6. 竞猜成功后获得固定奖励（`camp_arena_bid_reward=5|1|150`）。
7. 竞猜界面可查看双方阵容变化与战力对比。

---

## 八、结果展示与赛程

1. 当日活动结束后，进入活动界面展示四位阵营冠军。
2. 展示时间为当日比赛结束后至次日 `04:00`。
3. 赛程界面会随着淘汰赛进度实时更新。
4. 赛程界面可查看每场淘汰赛战报。
5. 本轮排行榜信息保留至下一次比赛日 `04:00`，到时统一清理。

---

## 九、特殊规则与边界情况

### 1. 奇数人数

1. 预赛：最后剩余玩家轮空，积分不变。
2. 淘汰赛：最后剩余玩家轮空并直接晋级。

### 2. 人数不足

1. 当人数不足以完整支持 8 人淘汰赛时，优先保证两两对战。
2. 例如 6 人场景下，八进四优先打满三场，而不是只打两场并轮空 2 人。
3. 剩余无法配对玩家轮空晋级。

### 3. 跨服相关

1. 分组规则固定在每周一 `08:00` 确认，不受活动本身是否开启影响。
2. 首次阵营竞技为本服参与；下一次阵营竞技起按分组规则进入跨服。
3. 所有显示玩家名字的地方需追加显示服务器名。

## 十、其他联动规则

### 1. 拍卖相关

1. 活动结束后开启拍卖。
2. 拍卖不是门派维度，而是**全服拍卖**。
3. 全服参与人数越多，拍卖产出越多。
4. 参与玩家均可获得分红。
5. 阵营冠军拥有提前竞拍资格。

### 2. 战斗相关

1. 仙阶压制生效。
2. 战斗规则同竞技场。
3. 战报支持跳过/倍速。
4. 战报视角中“我方在左”，存在镜像战报需求。

### 3. 系统消息与跑马灯

需支持以下消息类型：
1. 活动开启通知（2001）
2. 报名截止预告（2002）
3. 预赛开始预告（2003）
4. 押注提醒（2004）
5. 预赛出线全服通告（2005）
6. 晋级四强全服通告（2006）
7. 晋级决赛全服通告（2007）
8. 决赛胜出全服通告（2008）

### 4. 邮件

需支持以下奖励邮件：
1. 参与奖（mail id=61）
2. 八强奖励（mail id=62）
3. 四强奖励（mail id=63）
4. 亚军奖励（mail id=64）
5. 冠军奖励（mail id=65）
6. 支持奖/竞猜成功奖励（mail id=66）

## 十一、界面与表现

### 1. UI模块

根据 Excel 标题，阵营竞技 UI 至少包含以下模块：
1. 大厅
2. 观战
3. 我的比赛
4. 赛程
5. 其他信息区

### 2. 交互模块

根据 Excel 标题，交互至少覆盖以下流程：
1. 进入活动
2. 参赛
3. 观战
4. 冠军展示

### 3. 美术需求

1. 活动报名界面插图
2. 预赛场景
3. 单屏战斗场景
4. 冠军展示场景
5. 赛程背景
6. 冠亚位光效
7. 冠军展示光效
8. 其他渐进渐出特效

### 4. 预赛表演规则

1. 预赛开始时展示“我方形象（左）”与“第一轮匹配对手形象（右）”，播放 idle。
2. 每轮倒计时结束后，相关 UI 消失，双方靠近互相攻击并播放打击特效。
3. 我方胜利时：败方播放 dead 并渐隐消失，我方回到原位，然后下一名对手从屏幕外进入。
4. 我方失败时：胜方渐隐消失，我方播放 dead，完全消失后重新站起回原位，再进入下一轮展示。
5. 表演时间占用下一轮倒计时，因此整体表现需短平快。

## 十三、关键业务规则汇总（测试重点）

1. 活动解锁、入口显示、周期开启时间由配置控制。
2. 报名是参与资格前置条件，未报名不可参赛。
3. 报名时即根据玩家阵容与阵营规则分配阵营，报名后阵营固定。
4. 预赛为 20 轮积分赛，初始积分 100，胜+10，败-10，积分不能为负。
5. 第一轮与后续轮次的匹配规则不同，后续轮次需避开已交手对手。
6. 每个阵营前 8 名进入淘汰赛，未出线玩家立即发参与奖。
7. 淘汰赛为阵营内三局两胜制，八进四→四进二→二进一。
8. 奇数人数轮空、人数不足时优先保证两两对战，是关键边界。
9. 淘汰赛期间已解锁活动的玩家可观战并竞猜，每轮仅能下注 1 人且不消耗元宝。
10. 冠军展示、赛程、排行榜信息保留到次日 04:00 后清理。
11. 奖励发放涉及活动奖励、竞猜奖励、邮件、系统消息、跑马灯、拍卖联动。
12. 首次活动为本服，后续按规则跨服；所有玩家名展示处需带服务器名。
13. 战斗规则继承竞技场，包含仙阶压制、跳过/倍速、镜像战报等需求。
